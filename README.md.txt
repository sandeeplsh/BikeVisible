
# BikeVisible

A minimal cross-platform Progressive Web App for bicycle
rear visibility.

## Features
- Full-screen red display
- Start and stop controls
- Screen-awake request where supported
- Basic offline caching

## Run locally
Serve the files from localhost using a local web server.

## Publish
Upload the project to a public GitHub repository and enable
GitHub Pages under Settings > Pages.

## Install
- Android: open the HTTPS website in Chrome and select
  Install app or Add to Home screen when offered.
- iPhone: open the website in Safari, tap Share, and select
  Add to Home Screen.
- Desktop: open the website in a supported modern browser.

## Safety
This is a prototype, not certified safety equipment.
Always use appropriate bicycle lights and reflectors.
